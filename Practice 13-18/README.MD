## О проекте

Веб-приложение для заметок, которое умеет работать без интернета, отправлять push-уведомления и показывать новые заметки сразу на всех открытых вкладках.

## Практическое занятие 13: Service Worker

В этом занятии был создан Service Worker, который позволил приложению работать без интернета. Настроены события install (кэширование файлов при первом открытии), activate (очистка старых кэшей) и fetch (перехват запросов). Теперь при отсутствии сети приложение берёт файлы из локального кэша и продолжает работать.

##  Практическое занятие 14: Web App Manifest

Приложение стало полноценным PWA — его можно установить на телефон как обычное приложение. Был создан файл manifest.json с настройками иконок, внешнего вида и поведения. Добавлены иконки разных размеров и мета-теги для Android и iOS. Service Worker обновлён, чтобы кэшировать манифест — теперь приложение корректно устанавливается на рабочий стол.

##  Практическое занятие 15: HTTPS + App Shell

Для работы Service Worker и других современных функций браузера потребовалось безопасное соединение. С помощью утилиты mkcert был настроен локальный HTTPS-сервер с самоподписанным сертификатом. Внедрена архитектура App Shell: каркас приложения (шапка, меню, основная область) отделён от контента и кэшируется отдельно. Service Worker настроен так: каркас грузится из кэша (мгновенно), а контент — сначала из сети, а если сети нет — из кэша. Теперь интерфейс показывается моментально даже при медленном интернете.

##  Практическое занятие 16: WebSocket + Push

Добавлена связь в реальном времени через библиотеку Socket.io. Теперь когда один пользователь добавляет заметку, она мгновенно появляется у всех, у кого открыто приложение (в других вкладках или даже на других устройствах). Также реализованы push-уведомления: сгенерированы VAPID-ключи, настроена подписка через PushManager, создан Node.js-сервер, который может отправлять уведомления всем подписанным пользователям даже когда браузер закрыт.

## Практическое занятие 17: Детализация Push (Напоминания)

Функционал уведомлений расширен: теперь можно создавать заметки с напоминанием на конкретную дату и время. Данные о напоминаниях хранятся в localStorage с уникальным идентификатором. На сервере создано хранилище активных таймеров (через Map и setTimeout), которое ждёт нужного момента и отправляет уведомление. В Service Worker добавлена обработка кнопки "Отложить на 5 минут" — при нажатии отправляется запрос на сервер, и напоминание переносится.

## Технологии

Бэкенд: Node.js, Express, Socket.IO, web-push, mkcert. Фронтенд: HTML, CSS (Chota), JavaScript, Service Worker API, Push Manager API, localStorage.

## Что умеет приложение

Обычные заметки: добавление, просмотр, удаление. Заметки с напоминанием: можно выбрать дату и время, в назначенный момент придёт уведомление. Работа без интернета: при первом открытии приложение сохраняет каркас (шапку, меню, кнопки), и потом даже без интернета интерфейс показывается мгновенно. Обновления в реальном времени: если открыть приложение в двух вкладках и добавить заметку в одной, то во второй сразу появится всплывающее сообщение. Push-уведомления: приходят даже когда браузер закрыт, можно нажать "Отложить на 5 минут" прямо в уведомлении.

## Как это работает

Безопасное соединение: приложение запускается через HTTPS (даже на локальном компьютере), потому что без этого Service Worker не работает. Каркас приложения: минимальный набор файлов (шапка, меню, основная область) кэшируется при первом посещении и потом грузится мгновенно, а содержимое подгружается отдельно. Service Worker: это фоновый помощник, который перехватывает запросы и решает - взять данные из кэша (быстро) или из интернета (свежие). WebSocket: постоянное соединение между браузером и сервером, позволяет серверу самому отправлять данные без запроса от клиента. Push-уведомления: сервер хранит список подписок и в нужный момент отправляет уведомление всем подписанным пользователям. Напоминания: сервер запоминает время и через setTimeout ждёт нужного момента, затем отправляет push.

## Структура проекта

Папка content содержит home.html (главная страница с формами и списком заметок) и about.html (страница "О приложении"). Папка icons содержит иконки для уведомлений и установки приложения. index.html - каркас приложения (шапка, меню, основная область). app.js - вся логика на клиенте (навигация, заметки, подключение к серверу, подписка на уведомления). sw.js - Service Worker (кэширование, уведомления, обработка нажатий). manifest.json - настройки для установки приложения на телефон. server.js - сервер на Node.js (Express, Socket.IO, планирование напоминаний). package.json - список зависимостей.

## Проверка работы

Откройте приложение по адресу https://localhost:3001. Нажмите "Включить уведомления" и разрешите их в браузере. Добавьте обычную заметку - она появится в списке. Откройте вторую вкладку и добавьте заметку в первой - во второй появится сообщение. Добавьте заметку с напоминанием (выберите время через 1-2 минуты) - дождитесь уведомления. Отключите интернет и обновите страницу - приложение продолжит работать. Нажмите в уведомлении "Отложить на 5 минут" - напоминание перенесётся.
