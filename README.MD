# Интернет-магазин спортивных товаров
## О проекте
Веб-приложение для управления товарами спортивного магазина. Разработано в рамках практических занятий 4 и 5.

## Что сделано
Бэкенд: Express сервер с CRUD операциями для товаров
Фронтенд: React приложение со списком товаров, добавлением, редактированием и удалением
Товары: 10+ спортивных товаров (мячи, кроссовки, гантели, велосипед и др.)
Swagger документация
Добавлена интерактивная документация API

## Основные возможности
Просмотр всех товаров
Добавление новых товаров
Редактирование существующих товаров
Удаление товаров
Интерактивная документация API
Валидация введенных данных
Адаптивный дизайн

## Доступна по адресу: http://localhost:3000/api-docs
