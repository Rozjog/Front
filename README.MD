# Интернет-магазин спортивных товаров
## О проекте
Веб-приложение интернет-магазина спортивных товаров с полноценной системой авторизации, разграничением прав доступа и CRUD операциями. Проект выполнен в рамках практических занятий 4-10 по дисциплине "Фронтенд и бэкенд разработка".

## Технологии
Бэкенд: Node.js, Express, JWT (jsonwebtoken), bcrypt, Swagger (OpenAPI). Фронтенд: React, React Router, Axios, SCSS.

## Роли и права
Пользователь (user) может только просматривать товары. Продавец (seller) может создавать, редактировать и просматривать товары. Администратор (admin) имеет полные права: управление товарами (создание, редактирование, удаление) и управление пользователями.

## Аутентификация
Реализована регистрация с хешированием паролей через bcrypt. При входе пользователь получает пару токенов: access-токен (живет 15 минут) и refresh-токен (живет 7 дней). Когда access-токен истекает, фронтенд автоматически отправляет refresh-токен на сервер и получает новую пару токенов, что позволяет пользователю оставаться в системе без повторного ввода пароля.

## API Маршруты
Аутентификация: 
POST /api/auth/register (регистрация), 
POST /api/auth/login (вход с выдачей токенов), 
POST /api/auth/refresh (обновление токенов), 
GET /api/auth/me (получение данных текущего пользователя). 
Товары: 
GET /api/products (список всех товаров, доступен всем), 
GET /api/products/:id (детальная информация, доступна всем), 
POST /api/products (создание, только продавец и админ), 
PUT /api/products/:id (обновление, только продавец и админ), 
DELETE /api/products/:id (удаление, только админ).
Администрирование — все маршруты только для админа:
GET /api/users (список пользователей), 
PUT /api/users/:id (обновление), 
DELETE /api/users/:id (удаление)
